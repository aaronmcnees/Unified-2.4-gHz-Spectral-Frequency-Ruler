# An Interactive 2.4 GHz Spectral Frequency Ruler

## One Spectrum. One Shared Coordinate System.

The central contribution of this project is the **CoyoteLabs A–T Unified Spectral Bin Model**.

The model organizes the 100 MHz field from 2400 through 2500 MHz into twenty consecutive 5 MHz bins labeled **A through T**. These letter bins provide a protocol-independent coordinate layer beneath Wi‑Fi, Bluetooth Low Energy, Bluetooth Classic, and Zigbee.

Wireless standards normally describe the same physical spectrum using unrelated channel numbers, widths, and spacing. The A–T model gives them a common reference system, allowing their centers, footprints, overlaps, and relationships to be compared directly.

This is not merely a collection of standard channel diagrams. It is a unified model for seeing how different radio systems occupy the same spectrum.

## Interactive Spectral Tracking

Select or drag a frequency anywhere within any field. The selected frequency is tracked across the complete ruler, showing its simultaneous position within:

- The A–T master spectral bins
- Wi‑Fi channel centers and overlapping channel footprints
- Bluetooth LE advertising channels 37, 38, and 39
- Bluetooth LE data channels 0–36
- Bluetooth Classic BR/EDR channels
- Zigbee / IEEE 802.15.4 channels 11–26

The synchronized vertical tracking makes it possible to follow one exact frequency through every protocol layer instead of interpreting each channel system separately.

## Why the A–T Model Matters

A Wi‑Fi channel number, Bluetooth channel number, or Zigbee channel number only has meaning inside its own standard.

An A–T coordinate describes the underlying spectral location itself.

This creates a shared vocabulary for:

- Comparing otherwise incompatible channel-numbering systems
- Seeing cross-protocol spectral overlap
- Distinguishing channel centers from total channel footprints
- Following one frequency through several radio technologies
- Explaining and discussing the 2.4 GHz spectrum without changing coordinate systems

**A–T is the unifying framework of the ruler—not a decorative label system.**

## Included Spectral Fields

- Twenty A–T master bins across 2400–2500 MHz

- Bluetooth Classic BR/EDR channels 0–78
